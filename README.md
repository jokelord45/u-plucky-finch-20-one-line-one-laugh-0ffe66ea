One funny line, 111 characters: **"My plant died, so I bought a plastic one. It died too. Now I water a rock — and honestly, the rock is thriving."** Escalating absurdity in three short beats — a real plant dies, then even the plastic one dies, so the narrator ends up watering a rock, and the rock is thriving. Self-deprecating, visual, no setup needed, and the punch lands on the last clause. Easy to repeat to someone else.

## Run

```sh
node main.ts
```

Writes the single line to `/output/entry.txt`.
